Perch 시작하기

Codex나 Claude Code에게 일을 맡겨 두면, 중간에 “이거 해도 돼요?” 하고 멈춰 있을 때가 있어요. Perch는 화면 구석의 작은 캐릭터로 승인 대기와 응답 도착을 알려 주는 Mac·Windows 앱이에요.

명령 실행 승인이 필요해요 · 1분째 대기 중
Mac 또는 WindowsmacOS 14 이상 · Windows 11 x64
Codex 또는 Claude Code둘 중 하나는 이미 쓰고 있어야 해요

버튼은 검수한 v0.1.22 설치 파일로 바로 연결돼요. 파일 목록에서 고를 필요는 없어요. 다른 버전은 최신 릴리스에서 확인하세요.

Codex·Claude Code를 아직 쓰지 않는다면 Codex 시작 안내 또는 Claude Code 시작 안내부터 확인해 주세요. 일반 Claude 채팅이 아니라 Code 모드나 Claude Code 개발 세션을 관찰해요. Perch는 무료이고, Codex·Claude 이용 조건과 비용은 별개예요.

명령어가 낯설면 AI와 같이 설치해요

기본 흐름은 내 기기용 다운로드 → 파일 확인 → 설치 → Perch 안에서 연결이에요. 아래 요청문을 복사해 이미 쓰는 Codex나 Claude에 보내면, 한 단계씩 도움받을 수 있어요. AI 이용료나 사용량은 별개이고 새 유료 도구를 살 필요는 없어요.

화면에서 막혔을 때

경고 문구나 버튼 이름을 AI에게 보내고 다음에 무엇을 누를지 물어보세요. 화면을 공유한다면 계정 정보·경로·요청 내용을 먼저 가려요.

설치 파일을 확인할 때

체크섬 비교를 부탁할 땐 설치 파일과 .sha256 파일을 실제로 읽어 대조해 달라고 해요. 파일을 직접 확인할 수 없는 환경이면 확인했다고 말하지 말고, 내가 할 순서만 안내해 달라고 해요.

Perch 무료 베타 설치를 도와줘. 나는 터미널과 PowerShell에 익숙하지 않아.
공식 안내: https://github.com/moonweave/perch-releases/blob/main/START-HERE.md
공식 배포: https://github.com/moonweave/perch-releases/releases/tag/v0.1.22

1. 내 운영체제를 먼저 확인하고 Mac 또는 Windows x64 설치 파일 하나를 골라줘.
2. 내가 직접 할 클릭을 한 단계씩 알려줘. 설치 파일을 실제로 확인하지 않았다면 비교했다고 말하지 마.
3. 확인을 부탁하면 같은 릴리스의 체크섬과 실제 설치 파일을 비교하고 결과를 알려줘. 체크섬은 안전성 인증이 아니야.
4. 설치와 설정 변경 전에 무엇이 바뀌는지 설명하고 내 확인을 받아줘. 보안 경고와 Codex 훅 신뢰는 내가 직접 판단할게.
5. 보안 기능을 끄거나 격리 속성을 제거하지 마. 관리자 권한, 유료 결제, 알 수 없는 스크립트 실행으로 우회하지 마.
6. 기존 Codex·Claude 설정과 다른 훅을 보존해. 일반 prepare --apply나 설정 전체 덮어쓰기로 복구하지 마.
7. 설치 뒤 Perch 연결에서 연결을 도와줘. Codex는 앱의 코딩 → Hook에서 Perch 훅만 검토하게 안내해줘.
8. 내가 읽기 전용 요청을 보낸 뒤 작업함에 새 요청·응답이 들어오는지 확인해줘. 응답 도착을 테스트·배포 성공으로 판단하지 마.
9. 막히면 변경을 멈추고 원인과 다음 선택지를 알려줘. 비밀값·원문 대화·개인 경로를 외부에 보내지 마.

AI 도움은 선택이에요. 혼자 설치하려면 아래 운영체제별 안내를 따라요. 파일 확인 명령은 펼쳐 볼 수 있도록 따로 모았습니다.

말풍선 색만 알면 돼요

Perch는 조용히 있다가, 사람이 봐야 할 때만 눈에 띄어요. 말풍선을 누르면 해당 작업을 열 수 있어요. 실행 중인 창을 찾지 못하면 직접 찾아 달라는 안내가 나올 수 있어요.

주황 · 답이 필요해요

승인이나 질문을 기다리며 작업이 멈춰 있어요. 가장 먼저 봐야 할 것.

보라 · 응답이 왔어요

답이 도착했어요. 테스트나 배포까지 끝났다는 뜻은 아니에요.

잔잔함 · 진행 중이에요

일하는 중이라 부르지 않아요. 무엇을 하는지만 작게 보여 줘요.

Mac 설치

Intel·Apple Silicon 모두 같은 파일을 받아요. 파일을 대조하고 싶다면 AI에게 실제 비교를 부탁하거나 펼침 안내를 직접 따라요. 설치·연결은 클릭으로 진행해요. Windows라면 Windows 설치로 이동하세요.

  1. 파일 내려받기 · 1분

    위의 Mac 다운로드를 누르면 설치 파일을 받아요. 원하면 Mac 파일 확인용 체크섬도 받아요. AI에게 맡길 때는 두 파일을 실제로 대조했는지 확인하세요. Source code나 고지 문서는 설치할 필요가 없어요.

    github.com · Perch 릴리스 (파일명 예시)

    선택: 파일이 바뀌었는지 직접 확인할게요 — 터미널 안내

    두 파일을 다운로드 폴더에 둬요. Perch DMG가 여러 버전이면 이번 버전만 별도 폴더로 옮겨 확인하세요. 터미널 앱을 열고 아래 명령을 복사해 실행해요. 별도 폴더를 쓴다면 cd 뒤의 경로도 그 폴더로 바꿔요.

    cd ~/Downloads
shasum -a 256 -c Perch-*-macOS-universal.dmg.sha256

    OK가 나오면 다음 단계로 가요. 다른 결과가 나오면 열지 말고 공식 릴리스에서 다시 받으세요. 체크섬은 파일 변경 여부만 확인하며 게시자를 인증하거나 보안 경고를 없애지는 않아요.

    AI에게 맡겼다면 실제 파일 비교 결과를 확인한 뒤 다음 단계로 가요. AI가 파일을 직접 확인하지 못했다면, 확인됐다는 답만 믿고 설치하지 마세요.

  4. Codex·Claude와 연결하기 · 두 운영체제 공통

    캐릭터를 오른쪽 클릭하고 Perch 전체 열기를 고르면 앱 창이 보여요. 여기서 딱 한 번 연결해 주면, 그 뒤로는 어떤 프로젝트든 알아서 찾아요.

    1. 왼쪽 메뉴에서 연결을 눌러요.
    2. 보라색 훅 연결 버튼을 눌러요.
    3. 무엇이 바뀌는지 알려 주는 확인창이 뜨면 허용하고 연결을 눌러요.
    Perch 훅 연결
    Perch 훅 연결

    설치된 도구에만 Perch 알림 줄을 더해요. 다른 설정은 건드리지 않아요.

    나중에취소허용하고 연결
    Codex는 훅 신뢰도 필요해요 승인하지 않은 훅은 조용히 건너뛰어요. Perch 연결 → Codex 설정 열기를 누르고, Codex 앱의 설정 → 코딩 → Hook에서 Perch 훅을 신뢰하세요. 목록이 안 보이면 Codex 앱에 프로젝트 폴더를 먼저 열어요. 터미널을 쓴다면 codex 입력창에서 /hooks로 Perch 훅을 검토할 수 있어요. Trust all and continue는 다른 훅도 함께 신뢰하므로 목록을 먼저 확인하세요. Claude Code에는 이 Codex 승인 단계가 없어요.

    ‘훅’은 도구가 현재 상태를 Perch에 알려 주는 연결 장치예요. Perch는 요청·응답의 짧은 요약과 안전하게 걸러낸 도구 단계를 이 기기에 보관해요. 훅 정의나 명령이 달라져 Codex 승인 필요가 다시 보이면 재검토하세요.

  5. 첫 말풍선 보기 · 작업 하나

    1. 프로젝트 폴더에서 Codex나 Claude Code를 열고 “확인만 출력하는 명령을 실행해줘. 파일은 수정하지 마.”처럼 읽기 전용 요청 하나를 보내요. 도구의 사용량은 소모될 수 있어요.
    2. 화면 오른쪽 아래에 캐릭터가 나타나고, 무엇을 하는지 작게 보여 줘요.
    3. Codex·Claude가 승인을 물으면 주황 말풍선이 떠요. 눌러서 그 창으로 가 답하면 돼요.

    처음 “답이 필요해요” 순간에 macOS가 알림 허용을 물어요. 허용을 누르면 다른 앱을 보고 있어도 알림으로 알려 줘요.

    연결 확인 연결의 상태가 연결됨이면 성공이에요. 연결 직후에는 “첫 작업이 들어오면 연결됨으로 바뀌어요”라고 보이는데, 작업을 하나 시키면 바뀌어요.

Windows 설치

Windows 11 x64용이에요. Windows ARM과 WSL 안의 세션은 현재 지원 대상이 아니에요.

운영체제별 받을 파일
기기설치 파일
MacPerch-<버전>-macOS-universal.dmg
Windows 11 x64Perch-<버전>-windows-x64-setup.exe

파일이 바뀌었는지 확인하고 싶다면 같은 이름 뒤에 .sha256이 붙은 파일을 추가로 받아요. 설치에 필요한 파일은 운영체제용 설치 파일 하나예요. 그 파일이 Assets에 없다면 해당 운영체제용 배포가 아직 없는 거예요.

  1. Windows 설치 파일 받기

    위의 Windows 다운로드를 눌러요. 원하면 Windows 파일 확인용 체크섬도 받아요. 현재 Perch 버전에서 Claude Code 훅을 쓴다면 Git for Windows도 설치해 두세요.

  2. 파일 확인은 선택이에요

    위의 설치 도움 요청문으로 AI에게 두 파일을 실제로 대조해 달라고 부탁할 수 있어요. 비교가 끝나지 않았다면 확인된 것으로 여기지 마세요. 직접 확인하려면 아래 PowerShell 안내를 펼쳐요.

    직접 확인할게요 — PowerShell 안내 펼치기

    두 파일을 같은 폴더에 둬요. 파일 탐색기로 그 폴더를 열고, 위쪽 주소 표시줄에 powershell을 입력한 뒤 Enter를 누르면 그 폴더에서 PowerShell이 열려요. 아래 명령을 붙여 넣고 실행하세요. 여러 버전이 있으면 이번 버전의 두 파일만 별도 폴더에 모아 확인해요.

    $files = @(Get-ChildItem -Name 'Perch-*-windows-x64-setup.exe')
if ($files.Count -ne 1) { throw 'Perch 설치 파일 하나만 두고 다시 실행하세요.' }
$file = ".\$($files[0])"
$expected = (Get-Content "${file}.sha256" -ErrorAction Stop).Split()[0]
$actual = (Get-FileHash $file -Algorithm SHA256 -ErrorAction Stop).Hash.ToLowerInvariant()
if ($actual -ne $expected) { throw '체크섬이 다릅니다. 설치하지 마세요.' }
'OK'

    OK가 나오면 다음 단계로 가요. 오류가 나오면 설치하지 말고 공식 파일을 다시 받아요. 체크섬은 게시자를 인증하지 않아요.

  3. 내 계정에 설치하기

    이전 버전을 쓰고 있다면 알림 영역의 Perch 아이콘 메뉴에서 Perch 종료를 먼저 골라요. 확인한 .exe 파일을 열고 설치 안내를 따라요. 관리자 권한 없이 현재 계정에 설치돼요. 코드 서명을 받지 않은 베타라 SmartScreen 경고가 나올 수 있어요. 공식 파일임을 확인하고 설치를 계속하기로 했다면 추가 정보 → 실행을 선택하세요.

    보안 기능은 끄지 마세요 스마트 앱 컨트롤이나 회사·학교 정책이 설치를 막으면 여기서 멈춰 주세요. 현재 무료 배포에는 코드 서명이 없으며, 서명된 버전의 제공 시기는 정해져 있지 않아요.

    설치 중 파일을 열 수 없다고 나오면 무시하지 말고 설치를 중단한 뒤 Windows를 재시작하세요. 업데이트·복구 안내를 확인해 주세요.

  4. Perch를 열고 도구 연결하기

    시작 메뉴에서 Perch를 열고, 위의 Codex·Claude 연결 절차를 따라요. Codex 훅 신뢰와 읽기 전용 요청으로 연결 확인하기는 Mac과 같아요. Perch 아이콘은 화면 위 메뉴 막대 대신 작업 표시줄 오른쪽 알림 영역에 있어요. 숨겨진 아이콘 ˄ 안도 확인하세요.

    Windows에서 직접 실행한 개발 세션만 관찰해요. Codex 작업은 앱에서 열 수 있고, 끝난 Claude 세션은 Windows Terminal 새 탭에서 이어서 열릴 수 있어요. 실행 중인 창은 직접 찾아야 할 수 있어요.

기본 캐릭터 6종 바로 고르기

젠 카피바라·모찌 냥이·미니멀 고스트·ORB 에디션·푸딩 아홀로틀·메이플 레서판다가 앱에 들어 있어요. 별도 팩을 내려받거나 가져올 필요는 없어요.

  1. 화면 구석 캐릭터를 오른쪽 클릭하고 캐릭터 바꾸기를 골라요.
  2. Pet → 기본 캐릭터에서 원하는 기본 캐릭터를 선택해요.

캐릭터는 외형만 바꿔요. Codex·Claude 연결이나 작업 기록은 그대로예요. 캐릭터가 안 보이면 아래 문제 해결을 확인하세요.

알아 두면 편한 것

캐릭터를 누르면

작업 말풍선을 보여 줘요. 작업 기록은 캐릭터 우클릭 → 작업 기록 열기에서 확인해요.

캐릭터를 우클릭하면

위치 옮기기, 캐릭터 바꾸기, 숨기기 메뉴가 나와요. 끌어서 옮겨도 돼요.

Mac 단축키

⌃⌥⌘O 가장 급한 작업 창 열기
⌃⌥⌘P 작업 기록 열고 닫기

화면을 공유할 때

Pet → 말풍선에 작업 내용 표시를 끄면, 요청 내용 대신 “진행 중” 같은 상태만 보여요.

Mac을 켜면 자동으로

Pet → Mac에 로그인하면 Perch 열기를 켜 두세요. 기본은 꺼져 있어요.

발표할 때

Mac 메뉴 막대 또는 Windows 알림 영역의 Perch 아이콘 메뉴 → Pet 1시간 숨기기. 한 시간 뒤 저절로 돌아와요.

밤에는 어둡게

Mac을 어두운 모드로 바꾸면 Perch도 함께 어두워져요. 따로 설정할 건 없어요.

자주 묻는 것

제 코드나 대화가 어디로 가나요?

Perch는 요청·응답의 짧은 요약, 도구 단계와 안전한 파일 이름 등을 이 기기에 보관하고 작업함·말풍선에 보여 줄 수 있어요. 경로·URL·비밀 패턴은 걸러내며, 작업 내용을 인터넷으로 보내지 않아요. 원래 Codex·Claude 서비스의 데이터 처리와는 별개예요.

화면을 공유할 때는 Pet → 말풍선에 작업 내용 표시를 끄세요. 요청 내용 대신 상태만 보여요. 문제가 생겨 공개 이슈를 올릴 때도 요청·응답 내용, 경로, 계정 정보가 보이는 화면은 그대로 올리지 마세요.

“그래도 열기” 버튼이 안 보여요

먼저 Perch를 한 번 열어서 경고를 띄운 뒤에 시스템 설정으로 가야 버튼이 생겨요. 회사나 학교에서 관리하는 Mac은 정책 때문에 버튼이 아예 없을 수 있어요. 이 경우 관리자에게 문의해야 해요.

설치했는데 캐릭터가 안 보여요
  1. Mac은 화면 위쪽 메뉴 막대, Windows는 작업 표시줄 오른쪽 알림 영역에서 Perch 아이콘 메뉴의 Perch 전체 열기를 골라요. Windows는 숨겨진 아이콘 ˄ 안도 확인해요.
  2. Pet → Pet을 항상 표시를 켜요.
  3. 우클릭 메뉴의 Pet 숨기기로 숨겼다면, Perch 아이콘 메뉴로 다시 불러올 수 있어요.
계속 “연결됨”으로 안 바뀌어요
  1. Codex·Claude Code를 프로젝트 폴더 안에서 새로 시작해 읽기 전용 요청 하나를 보내요. Windows에서는 WSL이 아닌 Windows 개발 세션인지 확인해요.
  2. Codex라면 연결에 Codex 승인 필요가 있는지 봐요. 있으면 Codex 설정 열기 → 코딩 → Hook 또는 터미널의 /hooks에서 Perch 훅을 신뢰해요.
  3. 수신이 안 되고 연결에 다시 연결이 보이면, 바뀌는 내용을 확인한 뒤 연결해요. 설정 변경 경고만 남은 경우는 다음 항목을 먼저 봐 주세요.
“Perch 밖에서 훅 설정이 바뀌었어요”라고 나와요

다른 곳에서 설정을 수정해 Perch의 자동 되돌리기가 막혔다는 뜻이에요. 반드시 연결이 끊겼다는 뜻은 아니에요. 새 요청과 응답이 작업함에 들어온다면 경고를 없애려고 다시 연결할 필요는 없어요.

새 작업도 들어오지 않으면 제공자 상태와 Codex 훅 승인을 먼저 확인하세요. 다시 연결하기 전에는 어떤 설정이 달라졌고 무엇을 남길지 확인해요. 다른 도구의 설정을 지우거나 설정 파일 전체를 삭제하지 마세요.

새 버전은 어떻게 받나요?

연결 맨 아래의 새 버전 확인을 누르면 내려받기 페이지가 열려요. 내 운영체제용 설치 파일과 체크섬을 받아 위의 파일 확인 절차를 마치세요. Perch 아이콘 메뉴에서 앱을 종료한 뒤 Mac은 기존 앱을 교체하고, Windows는 새 설치 파일을 실행해요. 기록과 설정은 남아요.

업데이트 뒤 Codex 승인 필요가 보이면 훅을 다시 검토해요. 새 이벤트가 들어오지 않고 다시 연결을 요구하면 변경 내용을 확인한 뒤 연결하세요.

Perch를 지우고 싶어요
  1. 연결 → 연결 해제와 기록 삭제를 펼쳐요.
  2. 전체 연결 해제를 누르고, 한 번 더 눌러 해제를 눌러요. Perch가 더한 훅만 제거해요.
  3. 기록도 지우려면 앱을 제거하기 전에 개발 기록 삭제 → 한 번 더 눌러 삭제를 눌러요. 연결을 모두 해제한 뒤에만 가능하고 지운 기록은 되돌릴 수 없어요. 화면 설정과 캐릭터 팩은 남아요.
  4. Perch를 종료해요. Mac은 응용 프로그램 폴더의 앱을 휴지통으로 옮기고, Windows는 Windows 설정 → 앱 → 설치된 앱 → Perch → 제거를 선택해요.

연결 해제가 실패하거나 설정 변경 경고가 있으면 앱 제거를 잠시 멈추고 Mac 문제 해결 또는 Windows 문제 해결을 확인하세요. Codex·Claude 설정 파일 전체를 지우지는 마세요.

체크섬 OK면 안전한 앱이라는 뜻인가요?

아니에요. 체크섬은 내려받은 파일이 릴리스에 적힌 값과 같은지 확인하는 값이에요. 파일이 바뀌지 않았다는 확인이지, 게시자의 신원이나 앱의 안전성을 인증하는 것은 아니에요. 공식 릴리스에서 받은 파일인지도 확인하세요.

파일 확인 명령은 위의 Mac 설치 또는 Windows 설치에 있어요.
