# Perch 공개 베타

Perch는 이 Mac이나 PC에서 실행한 Codex·Claude Code 개발 세션이 승인을 기다리거나 응답을 마쳤을 때 작은 캐릭터로 알려 줘요. 설치 뒤에는 [시작 가이드](https://github.com/moonweave/perch-releases/blob/main/START-HERE.md)를 따라 첫 알림까지 확인할 수 있어요.

## 필요한 설치 파일 하나만 받으세요

**[Mac 설치 파일](https://github.com/moonweave/perch-releases/releases/download/v0.1.27/Perch-0.1.27-macOS-universal.dmg)** · **[Windows 설치 파일](https://github.com/moonweave/perch-releases/releases/download/v0.1.27/Perch-0.1.27-windows-x64-setup.exe)**

설치하려는 기기에 맞는 파일 하나면 돼요. `.sha256` 파일은 원할 때 설치 파일이 바뀌지 않았는지 확인하는 용도예요. Source code 압축 파일과 문서·고지 파일은 설치에 필요하지 않아요. 파일이 보이지 않으면 [최신 릴리스](https://github.com/moonweave/perch-releases/releases/latest)에 해당 운영체제용 공개 설치본이 아직 없는 거예요.

| 기기 | 지원 버전 | 설치 파일 |
|---|---|---|
| Mac (Intel·Apple Silicon) | macOS 14 이상 | `Perch-0.1.27-macOS-universal.dmg` |
| Windows PC | Windows 11 x64 | `Perch-0.1.27-windows-x64-setup.exe` |

Codex 또는 Claude Code가 먼저 설치되어 있어야 해요. 아직 없다면 [Codex 시작 안내](https://developers.openai.com/learn/codex) 또는 [Claude Code 설치 안내](https://docs.anthropic.com/en/docs/claude-code/getting-started)를 확인하세요. Windows에서 Claude Code를 쓴다면 [Git for Windows](https://gitforwindows.org/)도 필요해요. Windows의 WSL 세션은 아직 지원하지 않아요.

현재 베타는 macOS Developer ID 서명·공증과 Windows 코드 서명을 받지 않았어요. 운영체제의 보안 경고를 무시하거나 보안 기능을 끄지 마세요. 설치를 계속할지 판단하기 어렵다면 해당 설치 안내를 먼저 읽고, 불편하면 멈춰도 괜찮아요. 체크섬은 파일이 바뀌었는지 확인할 뿐, 게시자나 안전성을 인증하지 않아요.

젠 카피바라·모찌 냥이·미니멀 고스트·ORB 에디션 4종이 앱에 들어 있어요. 별도 팩을 받지 않아도 **캐릭터 바꾸기**에서 고를 수 있어요.

직접 만든 그림을 쓰고 싶다면 **Pet → 내 캐릭터 만들기**를 여세요. 전체 캐릭터 요청문을 AI에 한 번 보내고, 완성된 그림 파일들을 한꺼번에 가져와 미리보기에서 확인할 수 있어요. 앱은 그림을 대신 생성하지 않으며, 전체 팩은 29개 그림이 필요해요. [나만의 캐릭터 만드는 방법](CUSTOM-CHARACTER.md)에서 순서와 검사 기준을 확인하세요.

Perch는 개발 세션 요약을 이 기기에 보관하고 인터넷으로 보내지 않아요. Codex·Claude 서비스의 데이터 처리와 AI에게 직접 공유하는 화면·파일은 각각의 조건이 적용돼요.

설치가 막히거나 앱을 지우려면 [Mac 문제 해결](https://github.com/moonweave/perch-releases/blob/main/RECOVERY.md) 또는 [Windows 문제 해결](https://github.com/moonweave/perch-releases/blob/main/RECOVERY-WINDOWS.md)을 보세요. 베타 이용 조건은 [여기](https://github.com/moonweave/perch-releases/blob/main/BETA-EVALUATION-RIGHTS.md)에 있어요.

버그나 의견은 [GitHub Issues](https://github.com/moonweave/perch-releases/issues)에 남겨 주세요. 공개 이슈에는 파일 경로, 요청 내용, 계정 정보 같은 개인정보를 적지 마세요.
